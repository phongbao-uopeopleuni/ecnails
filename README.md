# EC Star Nails & Spa

Mã nguồn website chính thức của EC Star Nails & Spa: https://www.ecstarnailsandspagreenvillenc.com

## Chạy tại máy

Cần Node.js 22 trở lên; không cần cài thêm package.

```bash
npm run build
npm run dev
```

Sau đó mở http://127.0.0.1:4173/home.

## Bản quyền

Nội dung, hình ảnh, logo và tên thương hiệu thuộc EC Star Nails & Spa. Không sao chép hay sử dụng lại khi chưa được cho phép.
